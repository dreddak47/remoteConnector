Set up your Mac

Do this once per Mac. It takes about a minute.

  1. ⌨️

    1. Run the install command

    Open Terminal on the Mac and paste this:

    git clone https://github.com/dreddak47/remoteConnector.git && cd remoteConnector && ./install.sh

    The script builds the helper, installs it to start at login, and walks you through the rest right there in the terminal.

  2. 🔒

    2. Grant Accessibility access

    The script opens System Settings → Privacy & Security → Accessibility for you. Click the lock to unlock, then turn on the toggle next to remoteconnector.

    This is what lets the helper move your mouse and type on your behalf — macOS requires it for any app that controls input.

  3. 🟢

    3. Look for the menu bar icon

    A small RC icon appears in your Mac's menu bar (top right). Click it — you'll see a 6-digit code and your Mac's name.

  4. 📱

    4. Pair your phone

    On your phone, open the connect page and tap + to add a Mac, then enter the code from the menu bar.
